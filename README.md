## Contenido del repositorio

- `index.qmd`: documento Quarto con el texto y el código en R.
- `index.html`: documento procesado con *Render* (`embed-resources: true`).
- `asadas_aresep.csv`: conjunto de datos abiertos *Acueducto comunales (ASADAS)* de la Autoridad Reguladora de los Servicios Públicos (ARESEP, 2019; licencia CC BY-SA 4.0), exportado en formato CSV desde <https://aresep.go.cr/datos-abiertos/acueducto-comunales-asadas/> el 3 de setiembre de 2026. El documento lo lee desde la URL *Raw* de este repositorio.

Los datos de población por cantón (INEC, 2023) se leen desde el archivo `cantones.csv` del [sitio del curso](https://pf0953-programacionr.github.io/2026-ii/).
